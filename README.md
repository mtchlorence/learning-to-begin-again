# Learning to Begin Again

A responsive educational mini-blog created as the final project for Coursera's **Learning How to Learn** course. It combines reflective storytelling, research-supported learning techniques, practical exercises, and an original study framework called the **BEGIN Loop**.

## Live project

The canonical Render URL can be added here after the first deployment.

## Topics covered

- Focused and diffuse modes of thinking
- Illusions of learning and retrieval practice
- Procrastination and emotion regulation
- Memory, chunking, testing, deliberate practice, sleep, and lifelong learning

## Features

- Warm, notebook-inspired editorial interface
- Responsive desktop and mobile layouts
- Semantic navigation and accessible heading structure
- Reduced-motion support
- Expandable five-question study-session review
- Original CSS artwork with no copyrighted media dependencies
- Consistently formatted research references

## Tech stack

- Next.js 15
- React 19
- TypeScript
- CSS
- Static export for Render

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

The static site is generated in `out/`.

## Deploy to Render

This repository includes `render.yaml`. In Render:

1. Select **New → Blueprint**.
2. Connect this GitHub repository.
3. Confirm the service name and deploy.

For a manual Static Site setup, use:

- Build command: `npm ci && npm run build`
- Publish directory: `out`
- Branch: `main`

## Project purpose

This project turns a difficult season of career transition into a reusable learning guide. It was written for peer reviewers, independent learners, and anyone rebuilding confidence while learning something unfamiliar.
